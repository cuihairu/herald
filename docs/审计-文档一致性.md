# 文档与源码一致性审计（2026-10-08）

按《文档与源码一致性审计规范》执行的全仓文档对码审计：枚举文档面 → 抽可验证技术主张逐条对码取证（每条给 file:line；空 grep 先验路径再下否定结论）→ 三类差异入表 → 以源码为真相修文档（禁反向改码）。

- 三类差异：**A** 文档超前于码（幽灵功能）/ **B** 码超前于文档（缺失）/ **C** 描述不符（口径、默认值、键名、行为）。

- 修复原则：源码是唯一真相；超前的删或标注、缺失的补、不符的改口径。审计后文档即审核基准。
